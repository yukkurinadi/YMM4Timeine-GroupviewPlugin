# YMM4TimelineGroupViewPlugin
YMM4のタイムラインでグループをハイライトするプラグイン。

YMM4の設定からいろいろ設定可能。

Harmonyを使っているためエラーが出る可能性があります。

## 制作者・プラグイン案
制作者▶▶[ゆっくりなぢ](https://x.com/yukkurinadi)

プラグイン案▶▶[左コントローラー](https://x.com/aoihou0518)

## 主な機能

### 自動で起動
このプラグインはバックグラウンドで動作するプラグインです。
### グループをハイライト表示
タイムラインからアイテムをグループにすると枠で囲まれます。
### 名前変更
グループ(数字)の部分をトリプルクリックすることで名前の変更が可能になります。

入力ボックスがでてきますが動かないです。

ちゃんと裏では名前変更ができているので安心してください。
### 設定
YMM4の設定からその他からこのプラグインの設定ができます。

色設定やプラグインのオンオフなどができます。

## インストール方法
このGithubリポジトリのReleaseからymmeをダウンロードし、ymmeを開くと自動でダウンロードされます。

## 注意
Harmony(非公開API)を使用しているためエラーが出てくる可能性があります。

その場合は[開発者](https://x.com/yukkurinadi)に連絡願います。
